# Ghadeer Dawwas Portfolio

Create a premium, modern, highly interactive bilingual personal portfolio website in BOTH Arabic and English for a professional working in Data Analysis and Software Development.

The website must fully support:

English language

Arabic language

LTR layout for English

RTL layout for Arabic

A visible language switcher

Automatic layout direction switching

Proper Arabic typography

Responsive bilingual design

Persistent language preference

The website should feel elegant, professional, modern, visually impressive, and suitable for attracting freelance clients, startups, and companies.

IMPORTANT:

This is Phase 1 of the project.

Focus mainly on:

Frontend

UI/UX

Responsive design

Internationalization architecture

Reusable components

Do NOT build the full backend yet.

However, structure the application so Supabase, authentication, database, storage, and an admin dashboard can be added later without redesigning the frontend.

TECH STACK:

React

TypeScript

Tailwind CSS

Reusable components

Clean scalable architecture

Responsive design

SEO-friendly structure

Internationalization / i18n architecture

Use a proper translation system instead of hardcoding Arabic and English text separately across components.

Prepare translation files such as:

/locales/en.json
/locales/ar.json

or an equivalent clean internationalization structure.

LANGUAGE SYSTEM:

Create a language switcher in the navigation bar.

Options:

EN
العربية

When English is active:

Direction = LTR

English content is displayed

When Arabic is active:

Direction = RTL

Arabic content is displayed

Navigation direction should adapt correctly

Icons and arrows should adapt when necessary

Alignment should adapt to Arabic naturally

Save the selected language so it remains active when the user returns to the website.

Do not simply translate text visually.

The entire user experience must adapt properly between RTL and LTR.
